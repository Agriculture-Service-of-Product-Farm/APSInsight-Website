Blocked, with the reason kept

  • Authentication beyond static bearer tokens: password, passkey, MFA, OIDC and SAML need an identity provider.
  • PostgreSQL and PostGIS are not deployed. SQL migrations are specified and not executed.
  • No object store, signed uploads, Arrow, Parquet, DuckDB or raster I/O.
  • No computer-vision runtime, no natural-language model, no satellite or agency connector, no external credential store.
  • The five planned ASPF products are contracts only. Each has tested contract coverage and a larger blocked remainder because the product does not exist yet.

Specified, not built

  • WebSocket and server-sent events. Clients poll.
  • Machine-learning training and evaluation. Only metadata of runs and models exists.
  • A durable job worker and scheduler. A deterministic lifecycle core is tested; workflows still run synchronously.
  • A map workspace, a plugin loader, offline sync, and metering beyond a per-process rate limit.
