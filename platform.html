A modular monolith with one engine.

Each capability is implemented once and applied to every entity kind. Domain science lives in a separate library. The Angular UI, HTTP API and CLI share the same data directory.

A record’s life

  • Draft, then active, then archived. Restoring an archive needs the admin role.
  • Archived records are read-only. Permanent deletion is only for archived records that are not on legal hold.
  • Every accepted change appends a full version. A rollback is a new version, so history is never rewritten.
  • Writes carry an expected version. A stale write is a retryable conflict, not a silent overwrite.
  • The audit log is a SHA-256 chain over each event plus the previous hash, checked every time the engine opens.
