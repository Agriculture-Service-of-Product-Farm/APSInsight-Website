# Security policy

## Reporting a vulnerability

Report a defect in this website privately.

- Email: sbruicesingh@haclon.in
- Or use **Security → Report a vulnerability** on this repository.
- Do not open a public issue for a security report.
- Do not include farm data, credentials, or another project’s source.

There is no bug bounty. We aim to acknowledge receipt within 3 working days.

## Scope

This policy covers the static files in this repository. Internal design of APSInsight is out of scope for public disclosure.

## Supported versions

The current files on `main`.
