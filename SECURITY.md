# Security policy

## Reporting a vulnerability

Report vulnerabilities **privately**.

- This website: email sbruicesingh@haclon.in, or use **Security → Report a vulnerability** on this repository.
- The APSInsight engine: use private vulnerability reporting on [SbruiceS/APSInsight](https://github.com/SbruiceS/APSInsight).
- Do **not** open a public GitHub issue or pull request for a security report.
- Include the page or commit, steps to reproduce, and impact as you understand it.

There is no bug bounty. We aim to acknowledge receipt within 3 working days and to agree a disclosure date with the reporter.

## Scope

This policy covers the public static website in this repository.

The engine has its own threat model and review in the engine repository. Do not paste exploit detail into a public issue.

## Supported versions

The current files on `main` of this website, and the latest commit on `main` of the engine. APSInsight is pre-1.0.

## What this site will not do

- No cookies, accounts, or uploaded farm data
- No third-party scripts, fonts, or analytics
- No secrets in the repository
