Security of this website.

This page describes the public website only. It does not describe the internal design of APSInsight, and it does not publish configuration, keys, or review notes.

What the site does

  • Static files. No account, no form, no upload, no analytics, no third-party font or script.
  • The only script is structured data for search engines. It does not run as a program. The content-security policy allows that block by its hash and nothing else.
  • No cookies. The page does not write storage in your browser.
  • Images and styles are loaded from this same site.
  • Pages are served over HTTPS by GitHub Pages. Transport headers such as HSTS are set by GitHub.

What it refuses

  • Farm records, names, phone numbers, and plot files. There is nowhere to submit them.
  • Source code and secrets of ASPF projects.
  • A public bug tracker post for a security report. Use the private address below.

Reporting

If you find a defect in this website, write to sbruicesingh@haclon.in. Please include the page address and what you observed. Do not send farm data, and do not open a public issue for a security report.

A machine-readable copy is at security.txt.
